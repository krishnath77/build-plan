# Build Plan — look and words (agreed in chat, 14 Nov 2026)

Tejas asked for a Minecraft-style feel. We build an **original** blocky, pixel-art world in that spirit.

**Never use:** the Minecraft name or logo, its font, textures, sounds, screenshots, or any of its characters, creatures or item art. No look-alikes of them either. Generic things (blocks, grass, stone, ores, a pickaxe, a chest, a map, XP) are fine when drawn originally.

## Words (Class 12 → Class 10)

| Flight Plan (Anuj) | Build Plan (Tejas) |
|---|---|
| Sortie (study block) | Quest |
| Briefing tab | Today |
| Flight plan tab | World map |
| Syllabus tab | Syllabus |
| Target tab | Blueprint |

| Ops room (parent view) | Base camp |

| Defence-tech line per chapter | "Where you see this" line (games, building, gadgets, everyday life), written by the AI brief |

Tone stays the same as Flight Plan: encouraging, never pressuring. Low-energy days are normal.

## Look

- **Palette (starting values, check contrast):** night-stone header `#23262E` (where Flight Plan uses navy), grass `#5DA130`, dirt `#8B5A2B`, sky `#6CB4EE`, gold accent `#F2C230` (where Flight Plan uses amber), diamond teal `#3ED1C8`, paper background `#F6F3EA`. Subject colours are in `c10-subjects.js`.
- **Type:** "Pixelify Sans" (Google Fonts, open licence) for headings, numbers and tab labels only; "DM Sans" for all reading text so briefs stay easy to read.
- **Shapes:** square corners, chunky 3 px borders with a light top-left / dark bottom-right bevel on cards and buttons; progress bars drawn as rows of blocks.
- **Icons:** simple original pixel icons on a 16×16 grid (block, pickaxe, map, book, chest, torch), drawn as inline SVG.
- **Motion:** a small block "pop" when a quest is ticked; respect reduced-motion settings.
- **App icon:** an original grass-topped block with "BP".
